# Harsh Titoria

Founder and CEO of [Nada](https://nadanetwork.com), India's first social network for arranged marriages. Families find a life partner for a son or daughter through relatives, friends and community matchmakers they already know, and the app shows through which people two families are connected.

I architected and built the platform end to end: Java on Vert.x, a Neo4j graph that records who knows whom and finds the paths between profiles, Redis, Firebase and AWS Mumbai, shipping as a Flutter app on both stores.

- [Play Store](https://play.google.com/store/apps/details?id=com.nadanetwork.nada_app) · [App Store](https://apps.apple.com/in/app/nada-matchmaking-matrimony/id6786328503)
- [Launch video](https://youtu.be/b5ZDcSqHlys)
- [LinkedIn](https://linkedin.com/in/harshtitoria) · harsh@nadanetwork.com

Before Nada, I spent three years at Dell Technologies building Java and Golang microservices for Secure Connect Gateway, Dell's remote-support platform. BTech and MTech from IIIT Gwalior.

Nada's code is private. The repositories here are from my college years.
